# Application error codes

User-facing errors are shown as:

```text
ERROR {code} — {MESSAGE}
```

API responses use:

```json
{
  "error": {
    "code": 2001,
    "key": "OPCO_NOT_FOUND",
    "message": "OPCO NOT FOUND"
  }
}
```

HTTP status remains separate for protocol. Source of truth: [`lib/errors/catalog.ts`](../lib/errors/catalog.ts).

## Number ranges

| Range | Domain |
|-------|--------|
| 1000–1099 | Auth / session |
| 1100–1199 | Common validation / access |
| 2000–2099 | Admin organization (OpCo / Partner) |
| 2100–2199 | Users |
| 2200–2299 | Currencies / rates / settings |
| 3000–3099 | Reports / upload / storage |
| 4000–4099 | Invoices |
| 5000–5099 | Reconciliation / consolidation |
| 6000–6099 | Notifications / reminders |
| 9000–9099 | System / unexpected |
